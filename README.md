
# Career Roadmap Tracker

## Introduction
The Career Roadmap Tracker is a web application that helps users plan career goals and monitor their progress.

## Features
- Create career goals
- Set target dates
- Add milestones
- Mark milestones as completed
- Track overall progress
- Edit and delete goals
- Save data using Local Storage

## Tools Used
- HTML
- CSS
- JavaScript
- Visual Studio Code
- Web Browser

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.

## Conclusion
This project provides a simple way to organize career goals and track personal development through milestones and progress monitoring.
